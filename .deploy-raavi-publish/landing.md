# Markdown فارسی را ساده شروع کنید

اگر در پاسخ یک ابزار هوش مصنوعی یا کنار یک پروژه با فایل `.md` روبه‌رو شده‌اید، نگران نباشید. Markdown فقط روشی ساده برای ساخت متن مرتب است.

> این متن را تغییر دهید. نتیجه همان لحظه در برگهٔ پیش‌نمایش دیده می‌شود و با دکمهٔ «بازگرداندن متن اصلی» همیشه می‌توانید از نو شروع کنید.

## Markdown چه مزیتی دارد؟

با چند نشانهٔ ساده می‌توانید تیتر، فهرست، پیوند و کد بسازید. فایل همچنان متن ساده می‌ماند؛ بنابراین سبک است، در ابزارهای مختلف باز می‌شود و برای یادداشت، محتوای هوش مصنوعی و مستندات مناسب است.

## چرا راوی ساخته شد؟

با افزایش استفاده از فایل‌های Markdown در جامعهٔ ایران و گسترش ابزارهای هوش مصنوعی، جای ابزاری خالی بود که کار با این فایل‌ها را برای کاربر فارسی‌زبان ساده کند.

راوی را ساختیم تا ایجاد، مدیریت و مطالعهٔ فایل‌های `.md` بدون دردسر انجام شود؛ با جهت درست فارسی، بدون حساب کاربری و بدون فرستادن محتوای سند به اینترنت.

## متن را بنویسید؛ نتیجه را همان لحظه ببینید

- [x] ویرایش و پیش‌نمایش زنده
- [x] نمایش درست فارسی و انگلیسی
- [x] مطالعه، کتابخانه و جست‌وجوی محلی
- [x] برجسته‌سازی، یادداشت و نمودارهای Mermaid

| قابلیت | نتیجه |
| --- | --- |
| جهت متن | فارسی راست‌به‌چپ و کد چپ‌به‌راست |
| کتابخانه | جست‌وجو و سنجاق فایل‌ها روی دستگاه شما |
| حریم خصوصی | بدون ارسال محتوای سند |

### کد هم در جهت طبیعی خودش می‌ماند

```js
const direction = isCode ? "ltr" : "rtl";
console.log("راوی آماده است");
```

## همکاری با فایل `.ravi`

می‌توانید روی فایل یکدیگر یادداشت بگذارید، بخش‌های مهم را برجسته کنید یا حاشیه بنویسید و سپس آن را با پسوند `.ravi` برای هم بفرستید.

فایل `.ravi` علاوه بر متن اصلی، تصویرهای استفاده‌شده، یادداشت‌ها، برجسته‌سازی‌ها و حاشیه‌نویسی‌ها را نیز همراه خود نگه می‌دارد. این قالب اختصاصی است و فقط با نرم‌افزار راوی باز می‌شود؛ برای نوشته‌های معمولی همان فایل `.md` کافی است.
