# ممیزی پیش از انتشار — ۲۱ شهریور ۱۴۰۵

وضعیت: **ممیزی کامل اولیه پایان یافت؛ گیت انتشار ناموفق است.**

این ممیزی روی کد محلی پس از انتشار 2.4.5 اجرا می‌شود؛ آمار و امضای نصب‌کنندهٔ
عمومی 2.4.5 به این checkout تعمیم داده نمی‌شوند. نسخه، tag، لینک‌های عمومی و
مانیفست به‌روزرسان تغییر نکرده‌اند.

## روش و شواهد

- فرمان: `npm run release:gate` با `RAAVI_TEST_BROWSER_CHANNEL=chrome` و
  `RAAVI_AUDIT_DIR=outputs/release-gate-2026-09-12-final`.
- Windows، Google Chrome 152.0.7977.83؛ آزمون‌های بومی در پروفایل‌های موقت Electron.
- دریافت Chromium همراه Playwright با HTTP 403 مواجه شد؛ اجرای اصلی از Chrome
  نصب‌شده استفاده می‌کند. شکست اجرای ابتدایی به‌علت نبود مرورگر، نقص محصول شمرده نمی‌شود.
- [وضعیت مراحل](../outputs/release-gate-2026-09-12-final/stages.json) و
  [لاگ مجموعهٔ عمومی](../outputs/release-gate-2026-09-12-final/browser.log).

مرحلهٔ عمومیِ تنظیمات جدید، ۲۸۹ آزمون در ۸۶ فایل را کشف می‌کند؛ چهار سناریوی تازهٔ
«دربارهٔ راوی» به آن افزوده شده‌اند. با ۴۸ سناریوی اختصاصی، پوشش برنامه‌ریزی‌شدهٔ
رابط و PDF بومی ۳۳۷ سناریو است. بازاجراهای یک سناریو به این تعداد اضافه نمی‌شوند.

از چند اجرا به‌دست آمده و به‌معنای قبولی یک اجرای کامل از build نهایی نیست.

## موارد باز پیش از انتشار

- وابستگی‌های علامت‌گذاری‌شده باید به‌روزرسانی یا از نظر دامنهٔ اثر بررسی شوند؛
  سپس گیت کامل تکرار شود. `npm audit fix --force` اجرا نشده است.
- انتخاب متن داخل سلول جدول پس از قالب‌بندی، فوکوس مورد انتظار را حفظ نمی‌کند؛
  همان شکست در بازاجرای مستقل روی build جدید تکرار شد (`rich-blocks.spec.ts:228`).
- آزمون کامل سند Mermaid تغییر ارتفاع حدود ۲۲٬۱۷۵ پیکسل گزارش کرد؛ علت باید بین
  رندر/مجازی‌سازی و روش اندازه‌گیری تفکیک شود. آزمون موفق شمار خروجی، این رفتار را تأیید نمی‌کند.
- پنج سناریوی P12/P13 هنوز از طراحی قدیمی انتخاب فرمت/حالت‌های خروجی استفاده می‌کنند؛
  بازنویسی آن‌ها باید کنترل‌های هشدار، تلاش دوباره و اندازهٔ لمس موبایل را حفظ کند.
- دوازده سناریوی ظاهر/اندازه، شامل تصویر مرجع، نظرها، Graph Viewer، صفحه‌های W02–W14
  و کنترل‌های موبایل، با قراردادهای قبلی اختلاف دارند. مقایسه با طراحی تأییدشده لازم است؛
  baselineها بدون بازبینی تصویر تغییر نکرده‌اند.

فهرست دقیق ۱۹ سناریو و آخرین وضعیت هر مورد در
[فهرست تشخیص](../outputs/release-gate-2026-09-12-final/triage.json) ثبت شده است.

## تغییرات هم‌زمان با ممیزی

پس از آغاز مجموعهٔ عمومی، کاربر دسترسی از نام هدر به «دربارهٔ راوی» و به‌روزرسانی
مستندات را درخواست کرد. این تغییرات پس از build ممیزی‌اند و جزو نتیجهٔ build اولیه نیستند.

- دکمهٔ بومی هدر به فرمان موجود `help.about` متصل شد؛ منوی «…» از قبل همین فرمان را دارد.
- ورودی با ماوس و Enter، بستن با Escape و بازگشت فوکوس در چهار ترکیب دو تم و
  اندازهٔ دسکتاپ/موبایل در رابط توسعه موفق شد؛ حفظ متن ویرایش‌شده نیز بررسی شد.
- آزمون‌ها در `tests/about-entry-points.spec.ts` ثبت شده‌اند و گیت عمومی آن‌ها را
  خودکار کشف می‌کند. [شواهد اجرای رابط](../outputs/about-entry-points-2026-09-12-verified/browser-results.json).
- CHANGELOG و README بخش «منتشرنشده» دارند. تاریخ و موارد ناقص 2.4.5 در دفتر
  تغییرات برنامه هماهنگ شدند؛ متن نگه‌داری محلی، AI و بکاپ اختیاری نیز اصلاح شد.
- build جدید و بودجه‌های حجم موفق شدند؛ TypeScript و lint فایل‌های تغییرکرده نیز
  موفق‌اند. چهار آزمون About روی خروجی ساخته‌شده، پس از تنظیم ناحیهٔ لمس موبایل
  به حداقل ۴۴ پیکسل، دوباره موفق شدند: [نتیجهٔ نهایی](../outputs/about-final-production-stable/browser-results.json)
  و [لاگ چهار آزمون](../outputs/about-final-production-stable.log). نمایش معرفی و تغییرات
  منتشرنشده، دو مسیر بازکردن، Enter/Escape، بازگشت فوکوس و حفظ متن بررسی شدند.
- فایل‌های `dist` در میانهٔ اجرای کامل جایگزین نشدند؛ تغییرات About پس از پایان
  آن ساخته شدند. [لاگ build جدید](../outputs/about-final-build.log).
- بسته‌بندی آخرین build نیز دوباره موفق شد: [لاگ بسته‌بندی نهایی](../outputs/about-final-packaging.log).
  خروجی در `.artifacts/electron-smoke-2.4.5-82996-1789217683111/win-unpacked` است؛
  این نتیجه آزمون نصب/ارتقا یا اثبات داشتن امضای سیستم‌عامل نیست.

آزمون نصب/حذف/ارتقا روی ماشین تمیز، ساخت macOS و امضای بسته‌های جدید در این
اجرای محلی انجام نشده‌اند. هیچ بسته یا اعلان عمومی منتشر نشده است.
