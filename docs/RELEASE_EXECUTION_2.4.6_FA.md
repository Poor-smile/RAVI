# وضعیت نامزد انتشار 2.4.6

این سند گزارش آماده‌سازی است؛ انتشار عمومی 2.4.6 هنوز انجام نشده است.
دامنهٔ جاری، GitHub Release نسخهٔ Windows و دو معماری macOS است. استقرار
نسخهٔ وب و Ravi Light و فعال‌سازی updater فعلاً انجام نمی‌شوند.

## هویت نامزد

- شاخه: `codex/release-2.4.6`، بر پایهٔ `70f945e`.
- تغییرات جاری دسکتاپ از checkout اصلی در یک worktree مستقل کپی شده‌اند؛
  فایل‌های تولیدشدهٔ سایت، آرشیوهای انتشار و دارایی‌های طراحی وارد نامزد نشده‌اند.
- نسخهٔ بسته و دفتر تغییرات داخل برنامه به 2.4.6 منتقل شده‌اند.
- نسخهٔ عمومی پیشین `v2.4.5` و بسته‌های آن دست‌نخورده‌اند.

## پیش‌بررسی

- ورود به GitHub و دسترسی ساخت Release تأیید شد. آزمون `git push --dry-run`
  برای شاخهٔ انتشار موفق بود؛ این آزمون چیزی به مخزن اضافه نکرد.
- قفل npm با وابستگی‌های نصب‌شده یکسان است. ممیزی npm پس از به‌روزرسانی Next،
  ابزار Cloudflare و Sharp، صفر آسیب‌پذیری گزارش کرد.
- کلید موجود Ed25519 با کلید عمومی برنامه تطبیق دارد؛ کلید جدید ساخته نشده است.
- تنظیمات OAuth محلی فقط در مسیرهای نادیده‌گرفته‌شدهٔ build حفظ شده‌اند.
- مخزن GitHub فاقد secrets امضای Apple است. فایل‌های مک بدون Developer ID و
  notarization خواهند بود؛ انتشار آن‌ها به انتخاب صریح `allow_unsigned=true`
  مطابق راهنمای انتشار نیاز دارد. کاربر در ۲۲ شهریور ۱۴۰۵ این انتخاب و آزمون
  نصب بستهٔ Windows بدون Authenticode روی runner موقت را صریحاً تأیید کرد.

## اعتبارسنجی جاری

شواهد محلی در `.artifacts/release-2.4.6-gate/` ثبت می‌شوند. تاکنون قفل وابستگی‌ها،
lint، TypeScript، build و سقف chunkها، ۶۱۴ آزمون واحد، ۱۵ سناریوی اصلاحات، ۲۰
سناریوی تم/اندازه، ۱۲ سناریوی جست‌وجو، PDF بومی و تولید و ویرایش ۱۰۸ فرمول
در Microsoft Word موفق بوده‌اند. مجموعهٔ عمومی رابط هنوز کامل و موفق نشده است.

آزمون‌های مبتنی بر رابط قبلی به قرارداد مستند جدید منتقل می‌شوند: دو دکمهٔ
هم‌وزن Word/PDF به جای radio، قاب یک‌پیکسلی صفحه، رنگ‌های جدید زمینه و حذف
تب‌های موبایل از میز دسکتاپ. پوشش مسیرهای کاربردی، بازگشت فوکوس و نگه‌داری سند
حفظ می‌شود. تصویر مرجع منوی «…» پس از بررسی بصری تغییرات به‌روز شده است؛
این کار جای آزمون عملکردی را نمی‌گیرد.

## موارد باز پیش از انتشار

- تکمیل و موفق‌شدن آزمون‌های عمومی و ثبت نتایج نهایی نامزد.
- ساخت و کنترل Installer نسخهٔ 2.4.6 و ثبت اندازه، SHA-256 و هویت app.asar.
- آزمون نصب تازه، حذف و ارتقا در Windows موقت؛ سیستم روزمرهٔ کاربر هدف این آزمون نیست.
- ثبت commit نهایی، tag همان commit و متن Release هماهنگ با CHANGELOG.
- ساخت DMG و ZIP روی runner بومی Apple Silicon و Intel و کنترل گزارش هر دو.
- ثبت وضعیت امضای واقعی و تکمیل همهٔ assetها پیش از اعلام تکمیل انتشار.

## نصاب اولیه و بازآزمایی

نصاب اولیهٔ Windows ساخته و قرارداد ساخت آن کنترل شد: ۱۲۲٬۵۶۷٬۳۴۰ بایت،
Authenticode برابر `NotSigned`. هش‌ها در `tests/fixtures/windows-release-2.4.6.json`
برای آزمون ارتقا از 2.4.5 ثبت شده‌اند و پس از ساخت نهایی دوباره کنترل می‌شوند.
این فایل هنوز منتشر نشده است.

آزمون نمودارهای سنگین در هر دو تم با اختلاف ارتفاع صفر موفق شد. helper آزمون
بستن Electron اکنون ابتدا پنجرهٔ سند را از مسیر واقعی Chromium می‌بندد تا
checkpoint قبل از قطع اتصال debugger کامل شود. پنجرهٔ پنهان نمودار از پنجرهٔ سند
با مسیر URL متمایز می‌شود. دو بازآزمایی مستقل این مسیر موفق بوده‌اند.

## آماده‌سازی CI

دسترسی API با مجوز push/admin مخزن تأیید شد. تنظیمات OAuth موجود در ساخت محلی
بدون درج مقدار در Git یا گزارش، با کلید عمومی GitHub رمزگذاری و در Secrets
مخزن ثبت شدند. Workflow مک آن‌ها را هنگام ساخت به فایل‌های نادیده‌گرفته‌شدهٔ build
منتقل می‌کند تا پشتیبان‌گیری Google Drive در هر دو پلتفرم پیکربندی داشته باشد.

بازآزمایی رابط‌های اصلاح‌شده و نمونه‌های Studio موفق شد. در ممیزی اولیه، بازیابی
دو سند بسیار حجیم پس از سومین راه‌اندازی به سقف زمان آزمون رسید؛ علت در حال بررسی
است و این مورد پیش از انتشار عمومی باید حل شود. ساخت Release پیش‌نویس و اجرای
آزمون نصب روی Windows موقت به معنی عبور از گیت یا انتشار عمومی نیست.
