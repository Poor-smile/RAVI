# راوی

ویور و ویرایشگر سبک Markdown فارسی با چیدمان راست‌به‌چپ و فونت IRANSansX.

## امکانات

- بازکردن یا کشیدن فایل‌های `.md` و `.markdown`
- ساخت فایل جدید با نام معتبر، انتخاب `.md` یا `.ravi`، عنوان اولیهٔ اختیاری و انتخاب محل ذخیره
- انتخاب پوشه و اسکن بازگشتی زیرپوشه‌ها برای ساخت کتابخانه‌ی محلی
- مرور درختی و جست‌وجوی فایل‌های کتابخانه
- سنجاق‌کردن فایل‌های مهم در بخش مستقل بالای کتابخانه، بدون حذف آن‌ها از پوشهٔ اصلی
- جلوگیری از دریافت خودکار تصویرهای خارجی برای حفظ حریم خصوصی
- ویرایش و پیش‌نمایش زنده
- رندر امن بلوک‌های استاندارد `mermaid` در فایل‌های `.md` و `.ravi`
- استودیوی نمودار فارسی با پیش‌نمایش زنده، خطای خط/ستون، تکمیل خودکار، نمونه‌های آماده، زوم، پن و تمام‌صفحه
- ساخت نمودار با دکمهٔ نوار ابزار یا `Alt+M` در هر دو چیدمان فارسی و انگلیسی و ویرایش همان بلوک با دوبارکلیک
- تغییر اندازهٔ دو پنل با درگ ستون میانی و جمع‌شدن خودکار پنل کوچک‌تر در آستانهٔ ۱۰٪
- پنهان‌کردن مستقل ویرایشگر یا پیش‌نمایش و بازگردانی آن‌ها از ستون میانی
- مینی‌منوی پنج‌آیکنی قالب‌بندی در محل انتخاب متن ادیتور
- تم روشن و تاریک با ذخیره‌ی انتخاب کاربر و تغییر نرم بدون پوشاندن متن
- نمایش نسخهٔ جاری، معرفی ویژگی‌های متمایز و دفتر تغییرات با کلیک روی لوگوی راوی
- سوییچ فشرده کنار نام راوی و میان‌بر `Alt+T` با عملکرد یکسان در صفحه‌کلید فارسی و انگلیسی
- قفل اسکرول دوطرفه میان ادیتور و پیش‌نمایش
- پشتیبانی از جدول، چک‌لیست، نقل‌قول و قطعه‌کد
- منوی شناور مینیمال برای هایلایت، کامنت و حاشیه‌نویسی در محل انتخاب متن
- تشخیص خودکار جهت متن: فایل کاملاً انگلیسی LTR و بلوک‌های بیش از ۷۰٪ انگلیسی در سند ترکیبی چپ‌چین
- حالت مطالعه‌ی تمام‌عرض
- فهرست خودکار و جمع‌شوندهٔ فصل‌ها در سمت راست حالت مطالعه
- هدر متمرکز حالت مطالعه با نام فایل، بازگشت به میز و نمایش هوشمند هنگام اسکرول رو به بالا
- نگه‌داری محلی آخرین نوشته
- دانلود نسخه‌ی ویرایش‌شده
- رابط واکنش‌گرا و قابل استفاده با صفحه‌کلید

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی نهایی:

```bash
npm run build
```

فایل‌های فونت در `public/fonts` قرار دارند و متن برنامه از آن‌ها استفاده می‌کند.
این فایل‌ها از دارایی موجود همین فضای کاری کپی شده‌اند؛ پیش از انتشار عمومی، دامنه‌ی مجوز فونت را بررسی کنید.

## نسخه‌ی ویندوز

برای اجرای نسخه‌ی دسکتاپ در محیط توسعه:

```bash
npm run desktop
```

برای ساخت نصب‌کننده‌ی آفلاین ۶۴بیتی ویندوز:

```bash
npm run desktop:pack
```

خروجی نصب‌کننده در پوشه‌ی `release` ساخته می‌شود. نسخه‌ی دسکتاپ از انتخاب‌گر
بومی پوشه و پنجره‌ی ذخیره‌ی ویندوز استفاده می‌کند و فایل‌ها را به سرور
نمی‌فرستد.

نصب‌کننده برای پسوندهای `.md` و `.markdown` ارتباط فایل ثبت می‌کند و به همین
دلیل با دسترسی Administrator برای همه‌ی کاربران نصب می‌شود. پس از نصب،
دوبارکلیک روی فایل Markdown آن را مستقیماً در راوی باز می‌کند. اگر ویندوز
قبلاً برنامه‌ی پیش‌فرض دیگری را برای این پسوندها ثبت کرده باشد، تأیید نهایی
باید یک‌بار توسط کاربر در پنجره‌ی Open with یا Default apps انجام شود.

## نسخه‌های Linux و macOS

ساخت کامل Linux باید روی میزبان Linux یا Docker فعال انجام شود:

```bash
npm run desktop:pack:linux
```

این فرمان AppImage، بستهٔ DEB و آرشیو `tar.gz` نسخهٔ x64 را در پوشهٔ
`release` می‌سازد. برای ساخت آرشیو portable از ویندوز، پس از دریافت باینری
صحیح Electron Linux از فرمان زیر استفاده کنید:

```bash
npm run desktop:pack:linux:portable
```

ساخت Universal برای Intel و Apple Silicon باید روی macOS انجام شود:

```bash
npm run desktop:pack:mac
```

این فرمان DMG و ZIP Universal تولید می‌کند. برای انتشار عمومی نسخهٔ macOS،
گواهی Developer ID و notarization اپل نیز لازم است.
