سندهای بلند و رفع جابه‌جایی تمرکز هنگام تایپ فرمول در این نسخه ارائه شده‌اند.

- سوییچ فشرده کنار نام راوی و میان‌بر `Alt+T` با عملکرد یکسان در صفحه‌کلید فارسی و انگلیسی

## میان‌برهای اصلی ویرایشگر

| فرمان | Windows / Linux | macOS |
| --- | --- | --- |
| جست‌وجو و جایگزینی | `Ctrl+F` | `Cmd+F` |
| نتیجهٔ بعدی / قبلی | `F3` / `Shift+F3` | `F3` / `Shift+F3` |
| واگرد | `Ctrl+Z` | `Cmd+Z` |
| انجام دوباره | `Ctrl+Shift+Z` یا `Ctrl+Y` | `Cmd+Shift+Z` |
| انتخاب تمام متن | `Ctrl+A` | `Cmd+A` |
| پررنگ / مورب | `Ctrl+B` / `Ctrl+I` | `Cmd+B` / `Cmd+I` |
| پیوند | `Ctrl+K` | `Cmd+K` |

میان‌برهای ویرایشگر با جای فیزیکی کلید کار می‌کنند و در چیدمان فارسی و انگلیسی یکسان هستند. فهرست کامل از راهنمای میان‌برهای داخل برنامه در دسترس است.

## اجرا

```bash
npm ci
npm run dev
```

مدیر بستهٔ مرجع پروژه `npm@11.16.0` و تنها فایل قفل وابستگی‌های JavaScript، `package-lock.json` است. نصب توسعه و CI با `npm ci` انجام می‌شود. بعد از تغییر وابستگی‌ها، `npm run verify:dependencies` باید تطابق نصب با قفل را تأیید کند. فایل `src-tauri/Cargo.lock` مستقل و مخصوص Rust است.

پیش از هر build، تطابق وابستگی‌ها با قفل کنترل می‌شود. آزمون امنیت و بازیابی Mermaid در Electron با `npm run test:mermaid-release` اجرا می‌شود و از پروفایل‌های موقت استفاده می‌کند. ارتقای `esbuild` در زیرشاخهٔ `@esbuild-kit/core-utils` برای رفع advisory ابزار توسعه ثبت شده و سازگاری تبدیل TypeScript آن آزمون دارد.

برای ساخت نسخه‌ی نهایی:

```bash
npm run build
```

فایل‌های فونت در `public/fonts` قرار دارند و متن برنامه از آن‌ها استفاده می‌کند.
این فایل‌ها از دارایی موجود همین فضای کاری کپی شده‌اند؛ پیش از انتشار عمومی، دامنه‌ی مجوز فونت را بررسی کنید.

## نسخه‌ی ویندوز

نسخهٔ رسمی ویندوز با Electron ساخته می‌شود. برای اجرای آن در محیط توسعه:

```bash
npm run desktop
```

برای ساخت پوشهٔ اجرایی بدون نصب‌کننده:

```bash
npm run desktop:dir
```

برای ساخت نصب‌کنندهٔ NSIS نسخهٔ ۶۴بیتی ویندوز و اجرای کنترل سلامت آن:

```bash
npm run desktop:pack
```

فایل اجرایی بازشده در `release/win-unpacked/Raavi.exe` و نصب‌کننده در
`release/Raavi-Setup-X.Y.Z-x64.exe` ساخته می‌شوند. نسخهٔ Electron از
انتخاب‌گر بومی فایل و پوشه، پنجرهٔ ذخیره و اتصال مستقیم به Codex CLI استفاده
می‌کند و فایل‌ها را بدون درخواست کاربر به سرور دیگری نمی‌فرستد.

در انتشار عمومی، Installer حجیم روی `dl2.gptt.ir` نگه‌داری می‌شود، manifest و
یادداشت نسخه از `ravi.poorsmile.ir` ارائه می‌شوند و هر نسخه همراه tag، changelog،
Installer و checksum در GitHub Releases نیز ثبت می‌شود. راهنمای کامل در
[`docs/RELEASE_GUIDE_FA.md`](docs/RELEASE_GUIDE_FA.md) قرار دارد.

نصب‌کننده برای پسوندهای `.md` و `.markdown` ارتباط فایل ثبت می‌کند و به همین
دلیل با دسترسی Administrator برای همه‌ی کاربران نصب می‌شود. پس از نصب،
دوبارکلیک روی فایل Markdown آن را مستقیماً در راوی باز می‌کند. اگر ویندوز
قبلاً برنامه‌ی پیش‌فرض دیگری را برای این پسوندها ثبت کرده باشد، تأیید نهایی
باید یک‌بار توسط کاربر در پنجره‌ی Open with یا Default apps انجام شود.

## نسخه‌های Linux و macOS

ساخت کامل Linux باید روی میزبان Linux یا Docker فعال انجام شود:

```bash
npm run desktop:pack:linux
```

این فرمان AppImage، بستهٔ DEB و آرشیو `tar.gz` نسخهٔ x64 را در پوشهٔ
`release` می‌سازد. برای ساخت آرشیو portable از ویندوز، پس از دریافت باینری
صحیح Electron Linux از فرمان زیر استفاده کنید:

```bash
npm run desktop:pack:linux:portable
```

ساخت Universal محلی برای Intel و Apple Silicon باید روی macOS انجام شود:

```bash
npm run desktop:pack:mac
```

این فرمان DMG و ZIP Universal تولید می‌کند. برای انتشار عمومی نسخهٔ macOS،
گواهی Developer ID و notarization اپل نیز لازم است.

برای ساخت بومی هر معماری به‌صورت جداگانه:

```bash
npm run desktop:pack:mac:arm64
npm run desktop:pack:mac:x64
```

Workflow فایل `.github/workflows/release-macos.yml` روی GitHub Actions هر معماری
را روی سخت‌افزار واقعی متناظر می‌سازد: `macos-15` برای Apple Silicon و
`macos-15-intel` برای Intel. هر اجرا DMG، ZIP، گزارش معماری و SHA-256 تولید
می‌کند و فقط به یک GitHub Release موجود متصل می‌شود. انتشار unsigned به‌صورت
پیش‌فرض ممنوع است و تنها در اجرای دستیِ صریح با `allow_unsigned=true` مجاز می‌شود.

از انتشار 2.2.1، DMG هر معماری علاوه بر GitHub Release روی هاست دانلود
نسخه‌بندی‌شده قرار می‌گیرد و `stable.json` schema 2 آن را با اندازه، SHA-512 و
امضای Ed25519 مستقل معرفی می‌کند. برنامه فقط artifact معماری جاری را دریافت و پس
از اعتبارسنجی، نصب‌کنندهٔ استاندارد macOS را باز می‌کند.
