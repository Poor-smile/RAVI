## Scope and mode

لندینگ ایستای آمادهٔ هاست وردپرسی برای معرفی و ترغیب کاربر فارسی‌زبان به تجربهٔ راوی.

## Audience, job, and action

کاربرانی که فایل‌های Markdown فارسی می‌سازند، مدیریت می‌کنند یا می‌خوانند. صفحه باید در چند ثانیه مسئله، تفاوت محصول و محلی‌بودن آن را روشن کند و سپس کاربر را به تجربهٔ نمونهٔ زنده، نسخهٔ وب، دانلود یا حمایت برساند.

## Proof, content, and constraints

تصاویر واقعی نرم‌افزار، یک فایل محتوای اصلی `landing.md`، ویرایش و پیش‌نمایش محلی، بازنشانی محتوا، بدون حساب کاربری، CDN، پایگاه داده یا build. وضعیت فایل‌های انتشار باید صادقانه باشد.

## Direction and memorable moment

استعارهٔ «برگهٔ زندهٔ نمونه‌خوانی» از هویت فعلی راوی: کاغذ سرد، جوهر ذغالی، آبی علامت‌گذاری و ستون متن/نتیجه. لحظهٔ ماندگار، تغییر مستقیم Markdown و دیدن نتیجه در همان سند معرفی است.

## Unresolved release inputs

نشانی نهایی فایل‌های رسمی Windows، macOS و Linux نسخهٔ ۱.۰.۰ هنوز ارائه نشده است؛ تا آن زمان وضعیت آن‌ها غیرفعال و شفاف می‌ماند.
